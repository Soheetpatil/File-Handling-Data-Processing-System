# 📂 File Handling & Data Processing System

A Python-based command-line application that allows users to read, process, analyze, and export data from CSV and TXT files. The system provides powerful data manipulation features including filtering, sorting, searching, summary statistics, and file exporting.

## 🚀 Features

* Read CSV and TXT files
* Display file contents in a structured format
* Filter records based on field values
* Sort data alphabetically or numerically
* Search records using keywords
* Generate summary statistics for numeric fields
* Export processed data to CSV or TXT files
* Error handling for invalid files and user input
* User-friendly menu-driven interface

## 🛠 Technologies Used

* Python 3
* CSV Module
* File Handling
* Exception Handling
* Datetime Module
* Object-Oriented & Functional Programming Concepts

| Format | Support |

2. Display Current Data

### Sorting

### Statistical Summaries

Generate:

* Total Records
* Average Values
* Maximum Values
* Minimum Values
* Count of Numeric Records

## ⚙️ Installation

Clone the repository:

```bash
git clone https://github.com/Soheetpatil/File-Handling-Data-Processing-System.git
```

Move into the project directory:

```bash
cd File-Handling-Data-Processing-System
```

## ▶️ Run the Application

```bash
python main.py
```
